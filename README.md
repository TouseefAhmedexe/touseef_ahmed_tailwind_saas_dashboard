# Bloomrix SaaS - Tailwind CSS Product Website & Customer Dashboard

A SaaS product website, customer dashboard, pricing calculator, and user profile management system built with Tailwind CSS CLI and Vanilla JavaScript.

## Setup & Build Instructions

1. Install dependencies:
   npm install

2. Run Tailwind CLI watcher:
   npm run watch

3. Build minified output CSS:
   npm run build

## Features
- Theme persistence stored in `localStorage`
- Dynamic billing pricing toggle
- Search, filter, and pagination on project records table
- Responsive breakpoints for mobile, tablet, and desktop
